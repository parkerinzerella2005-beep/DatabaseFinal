# DatabaseFinal
This project is for our Database Management System's class. It involves designing a system that uses PHP and SQL. The name of the projects/company we have decided to design is called ShipMyWhip.

Proposal for CMPS 460 - Database Project
Database Application for Statewide Car Dealership Company: ShipMyWhip

by: Dell Savage (C00399589), Parker Inzerella (C00512851)
Project Description:
A statewide car dealership in Louisiana called ‘ShipMyWhip’ provides customers with a wide range of used or new cars, trucks, and motorcycles with the convenience option for delivery. They will also give their customers a variety of filter options to be able to find the best vehicle to match their accommodation. The main objective for this project is to implement a database to keep track of inventory of vehicles and be able to relate them to each other.

For this project, we plan to design and develop a database for car dealerships that operate several
locations within Louisiana. The dealership has a different inventory of vehicles at each location in the
state. The company will be managing vehicle information, sales, and customer records and whether they
are using the convenience shipping. The dealership sells many types of cars that vary by make, model,
year, mileage, and price. These dealerships will also have a chain of staff members that have roles,
salaries, and gender. These cars can also be moved to different locations.

This database application will make it easier to track and record which cars are available, which ones have been sold, where each vehicle is located, and the staff member that sold it. This will allow
ShipMyWhip to work more efficiently to maximize profits and customer satisfaction.
The database system is expected to support the following interactions:
A) List all vehicles currently available at a specific dealership location.
B) Find all vehicles sold during a specific time period.
C) Calculate the total sales amount for each dealership location.
D) Determine which employes has the highest sales in each month (employee of the Month).
E) Determine if a vehicle is checked as convenient delivery or not.
F) Identify customers who have purchased more than one vehicle.
G) Track when a vehicle was transferred from one location to another.
H) Update a vehicle’s status when it is sold or moved to a different location.
